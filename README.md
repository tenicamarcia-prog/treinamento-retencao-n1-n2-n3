# Treinamento de Retenção — N1 / N2 / N3

Apresentação interativa de treinamento de retenção para o time de suporte da **Ateky Internet**.

## Como colocar a apresentação online

1. Baixe o arquivo `treinamento_retencao_N1_N2_N3_apresentacao.html`
2. Neste repositório, clique em **Add file → Upload files**
3. Arraste o arquivo e **renomeie para `index.html`**
4. Clique em **Commit changes**

Depois disso, a apresentação ficará disponível automaticamente no Vercel (link abaixo).

## Link da apresentação

Após o upload, o site estará em:
**https://treinamento-retencao-n1-n2-n3.vercel.app**

(ou o link que o Vercel gerar)
